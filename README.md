# Beliko

Landing page for Beliko, a calm shared workspace for small teams.

Plain HTML, CSS and JavaScript with no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` – page markup and inline SVG icons
- `styles.css` – design tokens (light and dark themes), layout and components
- `script.js` – theme toggle, mobile menu, pricing toggle, scroll reveal, signup form
- `favicon.svg` – logo mark

The signup form is front-end only; connect it to your email or signup service before launch.
